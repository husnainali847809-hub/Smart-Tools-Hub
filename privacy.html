Privacy Policy

For SmartTools Hub Publisher · Effective date: November 13, 2026

This Privacy Policy explains how SmartTools Hub Publisher ("the app") handles information when it is used by its owner to publish content to Pinterest. The app is intended for the account owner's personal use, not as a service for other Pinterest users.

1. Information the app accesses

With the account owner's authorization, the app uses the Pinterest API to read the owner's own board information and create Pins on the owner's behalf. It does not intentionally access other Pinners' private information or other users' boards.

The publishing workflow also uses article text, titles, descriptions, image files and website URLs prepared for SmartTools Hub and related websites.

2. How information is used

  • To identify the account owner's Pinterest boards.
  • To create and publish Pins selected by the account owner.
  • To generate and publish website articles and associated graphics.
  • To record publishing state and avoid unintentionally publishing the same item again.

3. Storage and service providers

Automation settings and authorization credentials are stored as encrypted GitHub Actions secrets. Publishing state and generated website content may be stored in the connected GitHub repositories. Google Gemini may process prompts and article-generation inputs to produce written content. Pinterest processes API requests and Pins under its own terms and privacy policy.

The app does not sell personal information. It is not designed to collect personal information from people who view or save published Pins.

4. Sharing and disclosure

Information is sent only to the services needed to operate the workflow, including Pinterest, GitHub and Google Gemini. The app owner does not intentionally share account information with unrelated third parties.

5. Data retention and deletion

Generated articles, images and publishing records may remain in the connected repositories until the account owner deletes them. The account owner can revoke the app's Pinterest authorization through Pinterest's account/app settings and can remove stored credentials from GitHub Actions secrets.

6. Security

Access tokens and API keys should be kept in GitHub Actions secrets and must not be committed to public source files. No internet-based service can guarantee absolute security, so the account owner should promptly revoke credentials that may have been exposed.

7. Children's privacy

This personal-use publishing tool is not directed to children and is not intended to collect personal information from children.

8. Changes to this policy

This policy may be updated if the app's features or data practices change. The latest version will be published at this URL.

9. Contact

For questions about this policy or the app, use the project's public GitHub page: Pinterest automation repository.

This policy describes the current personal-use publishing workflow. If the app is later offered to other people or its data practices change, this policy and the Pinterest app registration details should be updated before that use.
